# Engenharia de Requisitos - Loja de Games

Documentação acadêmica de um sistema de gerenciamento interno para uma loja física de games, elaborada no curso de Análise e Desenvolvimento de Sistemas do UNISENAI Campus Florianópolis (2026).

## Objetivo

Planejar a elicitação de requisitos e organizar necessidades preliminares para controle de produtos, estoque, vendas, relatórios e perfis de acesso.

## Conteúdo

- [Trabalho revisado em PDF](docs/engenharia-requisitos-loja-games.pdf): processo incremental, partes interessadas, técnicas de elicitação, questionário com 41 questões em sete blocos e hipóteses de requisitos.
- [Histórico da revisão](docs/revisao.md): ajustes realizados e pontos que ainda exigem validação.

## Escopo e estágio

O cenário considera a operação interna de uma loja física. E-commerce e integração com marketplaces estão fora do escopo. Clientes da loja são partes interessadas indiretas; a equipe interna e a equipe técnica são os participantes previstos da elicitação.

Este projeto contém documentação de requisitos preliminares. Não inclui software implementado, entrevistas comprovadamente realizadas ou respostas de participantes reais. A tabela de necessidades apresenta hipóteses acadêmicas que ainda precisam de validação. O processo de desenvolvimento descrito é uma proposta para uma implementação futura.

## Aprendizados

- Delimitação do escopo e identificação de partes interessadas.
- Planejamento de questionários, entrevistas, observação e análise documental.
- Diferenciação entre requisitos funcionais, não funcionais e regras de negócio.
- Organização de um processo incremental e identificação de lacunas de validação.
